# Подключение Tuya / Smart Life

## 1. Облачный проект

1. [platform.tuya.com](https://platform.tuya.com) → **Cloud** → **Project Management** → **Create Cloud Project**. Дата-центр — **Central Europe** (для аккаунтов из России).
2. **Open Project** → **Overview**: скопируйте **Access ID** и **Access Secret**.
3. Там же, **Cloud Authorization IP Allowlist**: выключите или добавьте внешний IP клуба. Иначе будет ошибка 1114.

## 2. Привязка приложения

1. В проекте: **Devices** → **Link App Account** → **Add App Account** → **Tuya App Account Authorization**. Появится QR-код.
2. В Smart Life или Tuya Smart, под аккаунтом, где добавлены розетки: **«Я»** → значок сканера справа вверху → отсканируйте код и подтвердите. Права — **Controllable**.
3. **Devices** → **All Devices**: переключайте дата-центр вверху, пока не увидите розетки. Запомните его.

## 3. Программа

**Умный дом** → **Добавить систему** → **Tuya / Smart Life**: Access ID, Access Secret, дата-центр из шага 2.3 → **Проверить**.

## Ошибки

| Сообщение | Что сделать |
|---|---|
| код 1114 (`your ip ... don't have access`) | Выключите IP Allowlist или добавьте IP клуба (шаг 1.3) |
| код 1004 | Неверный Access ID или Access Secret |
| код 1106 | Отвяжите и заново привяжите аккаунт приложения (шаг 2) |
| код 28841002 | Истёк пробный период IoT Core: продлите в **Cloud** → **Cloud Services** |
| «Tuya не вернула ни одного устройства» | Привяжите аккаунт (шаг 2) и выберите в программе тот же дата-центр. Розетки должны быть в доме владельца аккаунта, а не в общем доступе |
| «без команды вкл/выкл пропущено» | Укажите «Код команды» в настройках (обычно `switch_1`) |
